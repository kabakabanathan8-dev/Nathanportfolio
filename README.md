# Portfolio professionnel — Nathan KABAKABA

Site vitrine statique en HTML, CSS et JavaScript, conçu pour fonctionner sur mobile et ordinateur.

## Fichiers
- `index.html` : contenu du site
- `style.css` : design responsive, animations et mise en page
- `script.js` : menu mobile, animations au défilement, portrait animé avec effet de profondeur et léger parallaxe et barre de progression
- `cv-nathan-kabakaba.pdf` : CV PDF lié au bouton de téléchargement
- `assets/nathan-kabakaba-portrait.jpg` : portrait intégré au profil
- `assets/contrepoids-ceo-original.png` : visuel original fourni

## Mise en ligne sur GitHub / Vercel
1. Téléversez les quatre fichiers à la racine du dépôt GitHub existant (remplacez les fichiers du site uniquement après sauvegarde).
2. Vérifiez que `index.html` se trouve à la racine.
3. Vercel détecte normalement le site statique automatiquement. Aucun framework ni commande de build n'est requis.
4. Ouvrez le lien Vercel sur téléphone et ordinateur pour tester les boutons.

## Personnalisation
Les visuels des cartes de projets sont des illustrations CSS originales, pas des photos de réalisations réelles. Remplacez-les ou ajoutez vos propres captures/photos lorsque vous serez prêt.
Le CV fourni est un résumé provisoire basé sur les informations communiquées. Ajoutez les formations, dates et expériences exactes avant de l'utiliser comme CV complet.


## Service ajouté
Photographie & audiovisuel : photo, portraits, événements, tournage vidéo et contenus visuels. Une animation CSS fait se séparer puis se regrouper les éléments de la caméra.
